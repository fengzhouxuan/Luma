# 1.13.3 通用发现身份及入口过滤验收

日期：2026-11-02。桌面测试位于 AOC2701、100% 缩放、900×640，位置 `(-1446,264)`。

## 实现范围

- 使用 Windows `IAppxFactory` 清单 API 读取应用 ID 与相对 EXE，并校验当前用户的包注册状态。只合并唯一匹配的默认 EXE，拒绝路径越界、共享 EXE 的多应用歧义及自定义参数入口；正式商店入口优先保留。清单缓存由修改时间与大小失效，注册状态逐次验证，读取失败时保留原入口。
- 同一 `Application` 目录的四段数字版本副本，文件长度及 SHA-256 相同时归一至稳定入口。校验上限 64MB；非浏览器带参数入口保持原身份，其他安装目录和不同内容不合并。
- App Paths 与安装记录校验图形程序及安装/维护特征，排除 OneDriveSetup、PowerToysUserSetup、winsdksetup、Realtek 更新维护工具和控制台程序；清单未声明为应用的包内 EXE 默认隐藏。
- 以数据文件方式读取 Unreal 引导器的 201/RCDATA 目标资源，不执行目标程序。只识别有界、相对、实际存在且位于引导器目录内的 Binaries/Win32 或 Win64 Shipping 目标；实际游戏进程默认隐藏，已固定、有别名或启动覆盖的直接入口仍保留。
