# Luma 1.8.0 验收记录

日期：2026-11-01。Luma 桌面交互在 AOC2701 显示器进行，沿用本机的外观、窗口位置和固定应用配置。

## 构建和自动化验证

- `npm test`：17 项通过。
- `cargo test --locked --lib --target-dir target/review-build`（在 `src-tauri` 运行）：47 项通过，4 项需要指定本机应用的可选测试忽略。
- `cargo fmt --all -- --check` 和 `git diff --check` 通过。
- `npm run tauri build` 通过，生成 x64 EXE 和 MSI 安装包。Vite 的资源体积提示为非阻断警告。
- 安装版 1.8.0 与最终构建的程序内容一致（校验时归一化 Tauri 安装类型标记）。

新增自动测试覆盖入口类型兼容、HTTP/HTTPS 地址校验、缺失目标和目标类型检查、旧版 v1 备份导入及 v2 类型往返、有效分类校验，以及带中文、空格、`&`、`!` 的脚本路径和参数。CMD 脚本通过隐藏测试进程实际执行并校验参数和工作目录；PowerShell 启动命令检查未添加执行策略绕过参数。
