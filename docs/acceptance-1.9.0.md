# Luma 1.9.0 验收记录

日期：2026-11-01。桌面操作在 AOC2701 上完成，未修改系统显示配置。

## 构建与自动化验证

- `npm test`：19 项通过。
- `cargo test --locked --lib --target-dir target/review-build`（在 `src-tauri` 运行）：55 项通过，4 项需要指定本机应用的可选测试忽略。
- `cargo fmt --all -- --check` 和 `git diff --check` 通过。
- `npm run tauri build` 生成 x64 EXE 与 MSI。Vite 的资源体积提示为非阻断警告。
- 安装后的 1.9.0 程序按 Tauri 安装类型标记归一化后与最终构建一致。

新增测试覆盖 Alt+1～9 与数字键盘映射、其他修饰键/重复按键/输入法组合的排除、本机与网络/协议入口的检查差异、快照与修复后的身份及个性化配置保留、清除自定义启动参数后的默认值恢复、备份中的显示密度和修复目标、逻辑尺寸在不同 DPI 与小工作区中的恢复，以及旧配置默认值。

本机发现测试只读取应用来源，入口快照保存明确在测试构建中停用，避免改写用户配置。
