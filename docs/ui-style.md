# Luma 界面样式参考

用户确认的参考：[StyleKit · Liquid Glass](https://www.stylekit.top/zh/styles/liquid-glass)，[完整示例](https://www.stylekit.top/styles/liquid-glass/showcase)。本文件作为后续界面检查与修改的基准，不依赖在线页面才能维护样式。

## 视觉方向

- 深色靛蓝基底与低饱和紫、青色光晕；玻璃表面叠加顶部高光和细折射边缘。
- 主容器默认 24px 圆角，弹层 28px，按钮与输入框使用相配的圆角；用户已有的窗口圆角配置继续生效。
- 玻璃层使用 40px 模糊、1.8 倍饱和度。Windows 原生 Acrylic 模糊桌面背景，WebView 中的 CSS 负责内部层次与高光。
- 主要操作使用偏深的粉紫渐变，普通操作使用半透明表面；选中项同时通过边框、背景和交互状态表达。
- 品牌字借鉴示例的渐变、青色细描边和光晕。应用名称、说明和路径保留清晰的浅色文字，适配启动器的小字号和高信息密度。

## 组件与状态

- `src/App.css` 集中维护颜色、玻璃层、边缘、间距、圆角与动效，避免新面板自行定义另一套外观。
- 主界面、设置、诊断、应用编辑、导入预览、右键菜单和通知使用同一套样式。
- 工具与分类使用统一线性 SVG 图标；程序本身的图标保持原样。
- 悬停有轻微位移与高光，按下轻微收缩，过渡约 500ms；窗口和卡片不持续变形。
- 键盘焦点始终可见；分类支持 Enter/空格选择，应用可获得键盘焦点，空状态、错误与禁用状态保持可辨认。
- 支持 `prefers-reduced-motion`、高对比和系统强制色模式；密集网格不为每张卡片重复使用重型模糊。

## 桌面验收

在 AOC 上检查文字与背景分离、原生模糊、圆角处无矩形残影、搜索输入、拖动、键盘导航、右键菜单、弹层滚动及关闭。原生圆角裁切应随窗口大小、缩放和用户圆角配置更新。

### 1.6.0 验收记录（2026-11-01）

- 本机安装版在 AOC2701、100% 缩放下验证主窗口、ChatGPT / TRAE 搜索、无结果提示、方向键选择、右键菜单、应用编辑、设置及诊断面板。
- 拖动后继续显示并能搜索，窗口位置恢复到测试前的 AOC 坐标；重复启动和重新安装后位置保持。
- 设置滚动时玻璃边缘固定于容器；圆角 24px → 12px → 24px 时原生裁切同步，测试后配置与测试前一致。
- 前端测试 10 项通过；Rust 测试 39 项通过、4 项本机可选检查跳过；TypeScript / Vite、Rust release、NSIS 与 MSI 构建通过。已核对本机安装文件与最终 release 构建一致（仅归一化 Tauri 安装类型标记）。
- 修复原生玻璃下系统标题栏残影，以及拖动后误判失焦收起的问题。物理断开显示器、其他 DPI 和系统强制色模式未在本轮桌面验收中模拟。
